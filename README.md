# Olive Glow

Create a modern, mobile-first Moroccan e-commerce landing page for a hair care spray called "OLIVARA".

LANGUAGE

- Entire website in Moroccan Darija (Arabic script).

- Keep the copy simple, trustworthy, and easy to read.

- Target audience: Moroccan men and women aged 18-50 suffering from hair loss, dry hair, weak hair, or damaged hair.

STYLE

- Premium, clean, elegant.

- White background with olive green (#4F6F52) and gold accents (#C9A227).

- Rounded cards, subtle shadows, smooth animations.

- Luxury cosmetic brand aesthetic.

- Fully responsive.

- Fast loading.
